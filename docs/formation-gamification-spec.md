# Executive Formation Path Gamification

## Intent

The gamification layer must support serious executive formation.

It should reinforce:

- continuity
- output quality
- practical synthesis
- artifact production
- cumulative discipline

It should not feel like a children’s app, a dopamine loop, or a public competition product.

## Use

The system uses:

- XP
- levels
- streaks
- badges
- unlockable modules
- progress map
- weekly rank by consistency
- portfolio milestones
- mastery scores
- reflection quality scores
- author completion
- concept mastery
- practice depth

## Level model

1. Technical Executor
2. Analytical Operator
3. Structure Reader
4. Decision Practitioner
5. Strategic Consultant
6. Executive Communicator
7. Commercial Operator
8. Founder-in-Formation
9. Structure Conductor
10. Executive Builder

## XP categories

- reading completed
- reflection submitted
- practice exercise completed
- decision memo completed
- structure analysis completed
- AI feedback reviewed
- weekly review completed
- monthly artifact completed
- public post drafted
- commercial artifact completed

## Weekly rank

Weekly rank should be:

- based on consistency and meaningful completion
- local to the user path or private cohort
- descriptive, not theatrical

Examples:

- steady
- strong
- top consistency band
- full-week discipline

## Anti-cheating

The system should protect against:

- empty submissions
- duplicate submissions
- low-value XP farming
- instant feedback-review clicking
- passive streak preservation without meaningful work

## Recovery

Recovery should soften punitive resets without making consistency meaningless.

Rule:

- long streaks earn limited recovery credits
- one missed day can be protected when a credit exists
- recovery is capped

## Dashboard

The dashboard should surface:

- XP
- current level
- streak
- recovery credits
- weekly consistency rank
- unlocked modules
- badges
- author completion
- concept mastery
- reflection quality
- practice depth
- portfolio milestones
